        How NumCheck works NumCheck reads slide figures and searches Excel using metric labels, periods, units, and layout. It compares the source value at the slide’s displayed precision. Inspect opens the original evidence. A verified figure reconciles to the supplied workbook. NumCheck flags figures it cannot trace. Local review needs no AI account or credits.
        AI can suggest which candidate label best describes a figure. You can also ask on demand from Inspect. Cloud providers receive labels and period names, which can include client or deal names. NumCheck masks figures in the text and compares values locally. Requests use the selected provider allowance.
